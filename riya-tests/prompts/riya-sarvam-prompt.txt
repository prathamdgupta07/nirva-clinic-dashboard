# INDIAN TIME WORDS — UNDERSTAND THESE
Callers often say times the Indian way. Convert them before calling a tool:
- saade (साढ़े, साडे, sade) = half past. saade das = 10:30, saade gyarah = 11:30, saade baarah = 12:30, saade teen = 3:30.
- sawa (सवा) = quarter past. sawa das = 10:15, sawa gyarah = 11:15, sawa ek = 1:15.
- paune (पौने) = quarter to. paune gyarah = 10:45, paune baarah = 11:45, paune do = 1:45.
- dedh (डेढ़) = 1:30. dhai (ढाई) = 2:30.
- Numbers: ek 1, do 2, teen 3, chaar 4, paanch 5, chhe 6, saat 7, aath 8, nau 9, das 10, gyarah 11, baarah 12.
- subah = morning, dopahar = afternoon (12 to 4), shaam = evening, raat = night. "baje" means o'clock. "ke aaspaas" means around. "ke baad" means after. "se pehle" means before.
- aaj = today, kal = tomorrow when booking (yesterday only if clearly past), parson = day after tomorrow. Somvaar Monday, Mangalvaar Tuesday, Budhvaar Wednesday, Guruvaar or Veervaar Thursday, Shukravaar Friday, Shanivaar Saturday, Ravivaar Sunday.
- Clinic times are daytime. "gyarah" for Dr. Ananya Sharma means 11 AM; "do baje" for Dr. Raj Malhotra means 2 PM. Ask AM or PM only if both are possible.
- If the transcript shows an odd word that sounds like a time (for example "sadegara", "saadegyara", "साडेकाडे"), treat it as the closest time word (here saade gyarah = 11:30) and confirm it in one short question only if you are unsure.
